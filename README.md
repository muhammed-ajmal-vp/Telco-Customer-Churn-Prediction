# Customer Churn Prediction Using Machine Learning

## Project Overview

Customer Churn Prediction is a Machine Learning project
that predicts whether a customer is likely to leave a
telecommunication service or continue using it.

This project uses the Telco Customer Churn dataset and
Logistic Regression algorithm to predict customer churn.

## Project Objectives

- Analyze customer data.
- Identify customer churn patterns.
- Clean and preprocess the dataset.
- Visualize customer churn information.
- Build a Machine Learning prediction model.
- Predict whether a customer will churn or not.

## Dataset Information

Dataset: Telco Customer Churn Dataset

Source: Kaggle

Total Records: 7043

Features include:
- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Phone Service
- Internet Service
- Contract
- Monthly Charges
- Total Charges
- Churn

## Machine Learning Algorithm

Logistic Regression

The model is trained using customer information
to predict whether a customer will leave the service.

## Model Performance

Accuracy: 78.75%

### Confusion Matrix

[[915, 118],
 [181, 193]]

| Class | Precision | Recall | F1-Score |
|-------|-----------|--------|----------|
| 0     | 0.83      | 0.89   | 0.86     |

## Customer Churn Prediction

The trained model predicts:

- CHURN
- NO CHURN

It also provides the probability of Churn
and No Churn for a customer.
